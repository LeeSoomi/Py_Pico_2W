2차시. 신호등을 내 마음대로 — 실습 코드

[배선]  괄호 = 보드의 물리 핀 번호
3V3(OUT)  (36) → 브레드보드 + 레일   ※ 5V(VBUS 40번, VSYS 39번) 연결 금지!
버튼      스위치 한쪽 다리 → + 레일(3V3)
          대각선 반대쪽 다리 → GP12(16) 그리고 10kΩ 저항 → GND 레일
          (외부 풀다운: 놓으면 0, 누르면 1)
빨강 LED  GP13(17) → 220Ω → LED(+) / LED(−) → GND
GND       (18) → 브레드보드 − 레일 (모든 GND 공통)
노랑 LED  GP14(19) → 220Ω → LED(+) / LED(−) → GND
초록 LED  GP15(20) → 220Ω → LED(+) / LED(−) → GND
보행 신호 내장 LED (배선 없음)

[실행]
코드 원본은 PC의 Pico2W_Class/Chapter02 폴더에 저장하고 F5로 실행합니다.
Pico 내부에 1차시 main.py가 남아 있으면 먼저 이름을 바꾸거나 삭제하세요.

[풀다운 저항 주의]
대부분 10kΩ으로 정상 동작합니다. 수업 전 보드마다 03_button_test.py로 "눌렀다 놓으면 0으로 돌아오는지" 확인하세요.
놓아도 1에 머무는 보드가 있다면 먼저 GP 번호와 물리 핀을 확인합니다 (예: 물리 16번 = GP12, GP16 = 물리 21번).
배선이 맞는데도 1에 머물면 RP2350 초기 칩의 E9 현상입니다 → 10kΩ 두 개를 병렬로 연결(5kΩ)하세요.
Pin.PULL_DOWN(내부 풀다운)만으로는 동작이 불안정합니다.
