4차시. 동작감지 보안 시스템 — 실습 코드

[시작 전]
3차시 회로(LED, 초음파, 서보)는 그대로 두고 PIR 센서와 부저만 추가합니다.
+ 레일은 3차시와 같이 5V(VBUS 40번)입니다.

[배선]  괄호 = 보드의 물리 핀 번호
PIR VCC  → + 레일 (5V)
PIR GND  → − 레일 (GND)
PIR OUT  → GP19(25)          ※ PIR 출력은 3.3V라서 분압 저항 필요 없음
부저 +   → GP20(26)          ※ 수동 부저(소리 높이를 PWM으로 조절)
부저 −   → GND(28) 또는 − 레일
LED      빨강 GP13(17) / 초록 GP15(20) — 2차시 그대로

[PIR 센서(HC-SR501) 설정]
시간 조절 손잡이(Time)를 끝까지 왼쪽으로 → 감지 유지 시간 최소(약 3초)
점퍼는 H(반복 감지)에 두기
전원을 켠 뒤 30~60초는 준비 시간 (이때 값이 들쑥날쑥한 것은 정상)

[파일 목록]
01_pir_test.py         실습1  PIR 감지 확인
02_buzzer_test.py      실습2  부저로 도레미
03_intruder_alarm.py   실습3  침입 경보기 (사이렌)
04_security_system.py  실습4  보안 시스템 (감지 횟수 + 시각 기록)
05_mission_log.py      심화   감지 기록을 log.txt 파일에 저장

[참고]
