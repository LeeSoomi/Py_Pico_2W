3차시. 자동문은 이렇게 — 실습 코드

[시작 전]
2차시의 버튼 회로(3V3 연결, 버튼, 10kΩ)는 빼고 시작합니다. LED 3개(GP13~15)는 그대로 둡니다.
브레드보드 + 레일을 3V3에서 5V(VBUS, 40번 핀)로 바꿉니다.  ※ 5V 레일에 GPIO 핀을 직접 연결하지 마세요.

[배선]  괄호 = 보드의 물리 핀 번호
초음파 VCC   → + 레일 (5V, VBUS 40번)
초음파 GND   → − 레일 (GND)
초음파 TRIG  → GP16(21)
초음파 ECHO  → 1kΩ → GP17(22),  GP17 → 2kΩ → GND   (5V 신호를 3.3V로 낮추기)
              (2kΩ이 없으면 1kΩ 두 개를 직렬로 / 3.3V용 HC-SR04P는 VCC를 3V3에, 분압 불필요)
서보 갈색    → − 레일 (GND)
서보 빨강    → + 레일 (5V)
서보 주황    → GP18(24)
LED          빨강 GP13(17) / 노랑 GP14(19) / 초록 GP15(20)  — 2차시 그대로
